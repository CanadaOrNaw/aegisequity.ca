Echo Home

Whole-House Local Voice & 7-Camera Vision

MODEL: ECHO-HOME-LOCALAUDIO: 5-ROOM PIPEWIRE + KOKOROVISION: 7 CAMERAS · FRIGATE + VLM
Operational Problem

Cloud smart speakers leak audio, rely on rigid command menus, and cannot reason over local security cameras or workstation tools.

Engineered System

Built a whole-house voice and vision system running 100% locally. A custom-trained "Echo" wake-word model (openWakeWord) feeds whisper.cpp speech-to-text into a local LLM agent (llama.cpp on Vulkan) that calls its own tools (time, weather, Exa search, local files, persistent memory) without hardcoded menus, speaking back through Kokoro neural TTS across a five-room PipeWire audio matrix. For computer vision, Frigate runs person and vehicle detection across seven cameras (including custom ESP32 camera nodes) with dual tuned CPU detectors so high-motion feeds never starve secondary cameras, paired with local Vision-Language Model evaluation on dark and low-frame-rate footage.
